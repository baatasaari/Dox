How It Works

Three Layers. One Control Plane.

📡

Layer 1: Observe

Every agent action emits a canonical event — tool calls, model responses, memory writes, errors, delegation, policy evaluations.

Events are ingested in real time via the SDK or REST API. Stored with cryptographic hashing for tamper-evident audit trails.

35 event types Batch up to 100
⚡

Layer 2: Evaluate

Every event is evaluated against your governance policies — configurable sentinels for tool misuse, injection, cost loops, hallucination, trajectory drift, delegation, bias, and regulatory breach.

Policy engine runs synchronously during ingestion. Matched policies trigger immediate interventions.

11 sentinel types 10 intervention actions
🛡️

Layer 3: Act

When a policy fires, Dox acts: warns the operator, blocks the tool call, pauses the agent, requests human review, or terminates execution.

Actions are logged to the tamper-evident audit trail. Webhooks dispatch to your SIEM, Slack, or PagerDuty. LangGraph workflows route escalations to human reviewers.

Automated Human-in-the-loop
Your Agent → Dox SDK → Event Ingestion → Policy Engine → Intervention → Audit Log → Webhook / Human Review → Compliance Report
